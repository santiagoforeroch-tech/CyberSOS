# Marca CyberSOS

## Idea central

**Vigilancia Violeta**: una identidad institucional, clara y humana para orientar y proteger frente a las ciberestafas.

## Logotipo

El símbolo es una **baliza SOS digital**: una alerta de emergencia protegida por ondas de red. Representa pedir ayuda a tiempo ante una ciberestafa. Usar el SVG original; no estirarlo, recolorearlo ni colocarle sombras ajenas.

## Paleta

- Violeta protector: `#7C3AED`
- Magenta de alerta: `#BE185D`
- Rosa de señal: `#F9A8D4`
- Tinta: `#271D3F`
- Fondo suave: `#FAF8FF`

## Voz

Clara, calmada y respetuosa. Explica el siguiente paso sin culpar a la persona que reporta.
